# Full Page Shot · 滚动归档

[简体中文](README.md) · [English](README.en.md)

<img src="icons/icon-128.png" alt="Full Page Shot 图标" width="80">

Chrome 扩展，提供 **F12 整页截图**和**滚动归档**两种模式：普通网页一键保存 PNG，长列表边加载边保存，再导出连续长图、PDF。支持小红书列表卡片的封面、标题、作者、原笔记链接，生成可搜索的离线收藏总览。

2.0 改用了边滚边保存的流程。已经保存的内容不会因网站回收屏幕外的 DOM 而丢失；不用将几百条收藏同时保留在页面上。

## 安装

从 [最新 Release](https://github.com/firmamento73/Chorme-Full-Page-Shot/releases/latest) 的 Assets 下载 `fullpage-shot-版本号.zip`。

1. 将发布 ZIP **真正解压**到一个固定文件夹。
2. 在 Chrome 打开 `chrome://extensions`，开启右上角“开发者模式”。
3. 点击“加载未打包的扩展程序”，选择直接包含 `manifest.json` 的文件夹。
4. 将扩展固定到工具栏。更新已有扩展时，将新文件放进原安装目录，再点击该扩展的刷新按钮。

安装无需构建。源码直接可用。Chrome 118 及以上。

## 更新到 2.2.3

F12 保持独立：调试连接失败、内部滚动正文无法完整截取时，只显示原因，不创建滚动归档任务，也不替你切换模式。需要时请自行选择“滚动归档”和“前台兼容截图”。预滚动仍是 F12 的可选加载步骤，不会改变截图模式。

新增统一的“保存位置”设置。F12、PNG、PDF、离线 HTML 和 JSON 使用同一目标文件夹；未设置时统一保存到 Chrome 下载位置下的“网页归档”，不再创建“整页截图”目录。

覆盖原扩展目录，在 `chrome://extensions` 刷新扩展，再刷新目标网页；弹窗应显示 **2.2.3**。缓存保留。连续导出会先尝试用旧片段的实际重叠像素修复重复接缝；被浮窗盖住的像素和跨次重扫的重复仍可能需要重新采集。

默认开启“无缝拼接”和“切换标签页后继续采集”。任务始终绑定启动时的标签页，通过 CDP 后台绘制继续滚动、等待和截图，不切换你的活动标签页。不同标签页可分别启动任务，面板可暂停其他页面任务；暂停一个不会停止另一个。已有 `debugger` 权限足够，没有新增全站权限。

取消后台采集开关只限制任务在前台运行，仍使用调试接口；要完全不使用调试连接，请勾选“前台兼容截图”。手动滚动原采集页、原页跳转、关闭原页、调试连接断开、改变窗口尺寸仍会暂停该任务；后台模式下切页或最小化本身不会触发暂停。Chrome 版本、网站加载逻辑和系统资源仍可能影响后台加载，超时会按已有规则暂停或标记。

## 使用

打开扩展面板，在顶部切换两种模式。两种模式都不需要手动打开 F12；建议关闭目标页的开发者工具，避免调试连接冲突；前台兼容截图不依赖调试连接。

### F12 整页截图

普通网页点击“一键 F12 整页截图”，通过 `Page.getLayoutMetrics` 获取当前文档尺寸，调用 `Page.captureScreenshot(captureBeyondViewport: true)` 保存一个 PNG，与 DevTools 的 `Capture full size screenshot` 使用同一路径。输出使用统一保存位置，不进入滚动归档缓存；重新打开面板可看进度、下载文件名或错误。

默认先预滚动触发懒加载（最多 200 屏，每屏约 120 ms），可以关闭以立即截图。默认临时隐藏悬浮控件，取消该选项可保留原页面外观。已有手动排除仍生效。结束、失败后恢复浮层、样式和原滚动位置，原选区也保留。

这个模式只截当前文档已保留的内容，预滚动不能解决虚拟列表回收，也不保证异步内容全部加载。F12 接口本身不能展开内部滚动容器。当检测到外层不滚动、正文在内部滚动时，面板会明确提示无法完整截取，由你自行切换到滚动归档。单边超过 16384 CSS 像素或总面积超过 6400 万 CSS 像素时明确提示切换模式，不静默截断。Chrome 实际渲染限制仍与设备比例、内存有关。同一标签页不能同时启动两种模式，其他标签页的采集不受影响。

### 滚动归档

1. 在浏览器中登录网站，打开目标页面和正确的收藏分类，关闭该页面的 F12 开发者工具。
2. 点击扩展图标，或按 `Alt+Shift+S`。
3. 默认自动识别正文滚动区域。外层页面可滚动时采集整个网页；外层不滚动时寻找主要的内部容器。多个区域难以区分时，点击“选择滚动区域”，再点击正文列表；按 Esc 可取消选择。“自动识别”清除手动选择。
4. 默认隐藏悬浮控件，同时记录可识别的笔记卡片。特殊遮挡可先点击“点选排除元素”，在页面上点选该浮层；可多次点选或清空，Esc 取消。设置每段最多等待的时间，点击“从顶部开始采集”。
5. 点击开始后弹窗自动关闭，程序准备原标签页的绘制后启动。后台模式下可浏览其他标签页；手动滚动原采集页会暂停，前台兼容模式下切页或最小化也会暂停。重新打开扩展弹窗可查看进度，不会因弹窗取得焦点而暂停。扩展按钮上的数字是已保存片段数。
6. 随时重新打开扩展，点击“暂停”“继续上次任务”或“结束采集”。点击“查看已保存结果 / 导出”，选择输出格式。

后台模式下打开结果页不会暂停原页采集；前台兼容模式下会暂停。已保存的部分可以随时导出。结果页不实时刷新，重新打开或刷新后可看到新增内容。

默认从顶部开始。选区功能选择的是**滚动容器**，不是任意像素矩形；点击普通正文时仍选择整个网页。暂不进入 iframe 内部，也不横向滚动。

## 保存位置

在扩展面板或结果页点击“保存位置”，打开设置页后点击“选择文件夹”，在系统对话框中选择并允许写入。之后所有截图和导出都直接保存到该文件夹，不再嵌套“网页归档”或“整页截图”子目录。设置会保留，同名文件自动加编号，避免覆盖已有文件。

未选择文件夹或点击“恢复默认”后，统一使用 **Chrome 下载位置 / 网页归档**。Chrome 默认下载位置通常是系统的“下载”目录；如果你修改了 Chrome 的下载位置，默认归档目录也随之改变。

自选目录通过浏览器授权直接写入，成功后显示“已保存到所选文件夹”，不会出现在 Chrome 的下载列表。浏览器重启或权限失效后可能需要在设置页点击“重新授权”；目录不可访问、磁盘写入失败时会明确报错，不悄悄改存到下载目录。取消选择文件夹会保留原设置。扩展无法读取文件夹的完整系统路径，因此设置页显示所选文件夹名称。

## 输出

- **单张连续长图 PNG**：流式编码完整像素行，不建立一个超高画布；500 条列表也可导出一张。浏览器或看图软件仍可能限制超高图的显示，文件大小与可用内存也有限。
- **分段长图 PNG**：可选，每张最多约 10000 像素高、2400 万像素。
- **单页连续长 PDF**：默认，一张长页面逐块排放截图，块与块相接，不插入边距或页间空隙。为兼容 PDF 页面尺寸限制，页面物理宽度可能缩小，嵌入图片保留原始像素。
- **A4 分页 PDF**：可选，按纸张比例分页、按体积自动分卷。最后一页可能有余白；PDF 阅读器显示的页间距属于分页视图。两种 PDF 都是图片，没有原始文字层。
- **离线收藏总览 HTML**：封面来自浏览器截图，文字和图片嵌在文件里。双击打开，可搜索标题和作者；链接返回原笔记。没有依赖外部图片地址。
- **采集记录 JSON**：包含来源、时间、停止原因、片段和笔记元数据、缺失和接缝提示，不包含图片本体。

连续导出默认要求同宽，先进行像素匹配、裁去重复区；原来独立保存的片段也会尝试修复。修复后仍存在未确认接缝时才提示；可选择分段输出，或主动勾选“强制顺序连接未确认的接缝”，接受可能的重复或错位。强制连接只是顺序排放，不推测或删除不确定内容。

默认下载位于 Chrome 下载位置的 `网页归档` 子目录；设置了文件夹时直接写入该文件夹。图像、任务进度和每个任务最后一张完整视口参照保存在扩展自己的 IndexedDB 中；可以在结果页删除缓存。清除扩展数据或卸载扩展会删除缓存，已经下载的文件保留。

总览保存的是列表卡片，不包含详情页全文、多图或视频。卡片未能完整进入截图区域时，保留文字和链接，并标记缺少封面；可以继续任务重扫补齐。

## 续采和完整性

点选排除只绑定当前页面中的元素，网站替换该元素会暂停并要求重新点选，网页刷新后也需重新点选；有点选排除的任务刷新后请创建新任务。改变排除元素或浮层开关后，也需从顶部创建新任务，避免混合旧截图。

已保存片段的任务不能改换截图接口后继续，以免混合不同像素比例；请从顶部创建新任务。兼容任务继续时始终使用兼容接口。

同一页面内暂停后继续：返回上次已保存位置，检查并采集后续内容。不要更改所选区域、收藏分类、窗口尺寸和缩放。

整个网页刷新后继续：从顶部重新扫描，以笔记 ID 去重并补封面；截图保留为新的一组片段，默认连续导出会提示多组截图。原先选择的内部滚动容器刷新后不能确认身份，需要重新选择并创建新任务。

网站显示明确的“没有更多内容”且当前区域加载完成时，标记“网站确认到底”。连续三轮在当前底部没有新内容而网站没有明确结束标记时，标记“完整性未确认”。主动结束、超时、加载失败和达到轮数上限，也会保留停止原因。不会单凭滚不动就声称所有收藏已保存。启动、调试连接和加载等待都有状态提示；加载等待会显示图片数、占位数及剩余时间。

默认图片加载失败或布局持续不稳定时暂停。可以启用“超时也保存，并标记缺失”；这种结果可能包含占位图，结果页和采集记录会明确标记。每次最多采集 1500 轮，达到上限后可继续。

## 页面适配和边界

加载检查覆盖可见的 `img`、字体、常见骨架屏和元素几何位置。页面上的 CSS 背景图、canvas、视频、闭合 Shadow DOM 或网站自定义占位逻辑可能需要单独适配。动画和动态页面无法保证是同一瞬间的完整快照。

悬浮处理发生在截图前：对可见的 fixed 控件、滚动时已吸附的小型 sticky 控件，以及浏览器顶层 popover / dialog 临时设置不可见，保留元素占位和正文布局。小型 sticky 内容在正常流中先保留，吸附后隐藏；所选滚动区域及其祖先、大型固定正文阅读区域受保护。每段截图前后检查浮层状态，监听动态插入和样式改变，并扫描开放 Shadow DOM；不根据“小红书”“下载笔记”等文字或站点 ID 判断。

过滤样式以扩展 USER 样式注入，避免页面 CSP 和普通 CSS 覆盖；开放 Shadow DOM 另有可恢复的局部样式与内联回退。隐藏的图片和控件不参与正文加载等待、笔记识别和接缝参照。暂停、结束或错误退出时移除过滤标记并恢复临时样式，不点击关闭按钮、不删除 DOM。

绝对定位也常用于真实卡片、图表和虚拟列表，因此不会把所有 absolute 元素一律隐藏。自动判断有歧义时用“点选排除元素”；默认优先选择点击元素最近的固定控件，防止误选外层的整个固定应用框架；否则排除被点击元素。取消勾选“采集时隐藏悬浮控件”可保留浮层，手动点选的排除仍生效。闭合 Shadow DOM 内的独立浮层、iframe 内部控件、canvas 内画出的按钮不能通用识别；若内容本身在弹窗中，先选择正文滚动区域。隐藏弹窗不会解除网站自身的滚动锁或加载门槛，需要先正常处理这些对话框。

每次截图保留一张完整视口作为接缝参照，按实际重叠像素校正拼接位置，不要求网页存在可识别的卡片或 DOM 标记。已确认的重复区只保留一次；底部后来加载出的内容会在未变化的连接区衔接，并替换旧尾部，修改与断点在同一事务提交。

默认无缝模式下，匹配失败会减半滚动距离重试两次；仍匹配不上时暂停，当前错位片段不会追加。取消无缝开关才按独立片段保留不确定截图。均匀空白、重复纹理、持续变化的内容或真正的重排可能无法自动判断，不能用强制连排代替可验证的接缝。

小红书适配识别 `.note-item`、`/explore/` 和 `/discovery/item/` 链接及常见标题作者节点。网站结构变化可能需要更新选择器。**用户提供的 2.0.1 实测 PDF 已确认能采集真实小红书页面，也暴露了浮层重复问题；新版浮层过滤、后台绘制尚需在用户本机确认。建议先试采一小批，再采集全部收藏。**

## 权限和本地数据

`activeTab` 和 `scripting` 用于用户点选的当前网页，前台兼容截图通过 `tabs.captureVisibleTab` 使用已有 `activeTab` 授权；`debugger` 用于浏览器真实截图；`storage` 用于最近任务记录；`downloads` 用于保存输出。没有常驻全站权限。`file://` 页面另需在扩展详情里允许访问文件网址。

调试截图时 Chrome 会显示调试提示，建议关闭目标页的 F12；兼容截图无需调试连接。采集和导出代码不向外部服务上传内容，网站加载仍使用浏览器原来的登录状态和网络连接。

## 开发与验证

兼容截图专项会注入用户截图中的原始连接错误，通过真实 Chromium 渲染验证滚动归档自动兼容、F12 失败不切换模式、切页／导航时丢弃截图、断点续采、截图频率限制及长图像素。测试不能替代用户 Windows Chrome 中其他扩展嵌入页面时的实际授权验证。

内部滚动修复已通过固定应用框架、侧栏、普通及隐藏滚动条容器、开放 Shadow DOM、暂停恢复和 F12 不支持时明确报错的模拟页面测试。测试不代表已经访问用户登录后的简道云待办数据。真正的自绘滚动、iframe 和闭合 Shadow DOM 仍可能需要单独适配。

无打包器，PDF 导出使用本地的 `vendor/pdf-lib.min.js`，附有原许可证。其他代码为原生 JavaScript。

```bash
node --test tests/core.test.js tests/seams.test.js
BROWSER_TEST_OUTPUT=1 python tests/browser_test.py
BROWSER_TEST_COMPAT=1 python tests/browser_test.py
BROWSER_TEST_CLASSIC=1 python tests/browser_test.py
BROWSER_TEST_DASHBOARD=1 python tests/browser_test.py
BROWSER_TEST_SEAMS=1 python tests/browser_test.py
BROWSER_TEST_INDEPENDENT=1 python tests/browser_test.py
BROWSER_TEST_OVERLAYS=1 python tests/browser_test.py
BROWSER_TEST_STARTUP=1 python tests/browser_test.py
python tests/browser_test.py
python scripts/package.py
```

浏览器测试需要 Playwright、Pillow、PyMuPDF 和 Chromium，可用 `CHROMIUM_BINARY` 指定浏览器可执行文件。测试页面模拟懒加载、固定栏、内部滚动、无限追加、500 条虚拟列表、图片失败和无结束标记。

保存位置专项使用浏览器真实目录句柄（测试中的 OPFS）、IndexedDB 持久化和文件写入，并模拟系统文件夹选择器与授权状态；这不等于验证本机系统选择器或重启后的授权保留。

当前云环境的管理员禁止加载未打包扩展，也禁止浏览器直接打开 `file://`。测试通过专用 API 桥接运行真实 Chromium 的滚动、渲染、CDP 截图和导出，生成的独立 HTML 通过本地 HTTP 检查，浮层专项结果位于 `dist/overlay-artifacts/`，后台和连续导出专项结果位于 `dist/independent-artifacts/`，逐像素接缝验证位于 `dist/seam-artifacts/`。桥接只位于 `tests/`，不进入发布 ZIP。**这不等于完成了实际扩展安装、用户手势授权、后台生命周期或本机离线文件打开验证。** 详见 [测试记录](测试记录.md)。
